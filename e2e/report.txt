Since your app is built using Next.js (App Router), you don't actually need external packages like `react-helmet` or `helmet`. Next.js has a built-in, native **Metadata API** (`export const metadata` or `generateMetadata`) that dynamically injects standard HTML `<title>`, `<meta>`, and OpenGraph/Twitter tags right on the server.

Here is a flexible boilerplate template you can reuse across static and dynamic pages, followed by a tailored title and description dictionary for all your routes.

---

### Standard Next.js Metadata Boilerplate Template

#### 1. Static Routes Template (`page.tsx` or `layout.tsx`)

For static routes (e.g., `/landing`, `/login`, `/admin/dashboard`):

```tsx
import type { Metadata } from "next";

export const metadata: Metadata = {
    title: "Page Title | TQP Portal",
    description: "A clear, concise 1-2 sentence description of what this page does.",
    openGraph: {
        title: "Page Title | TQP Portal",
        description: "A clear, concise 1-2 sentence description of what this page does.",
        url: "https://tqp.mssnoau.org/your-route-path",
        siteName: "TQP Attendance & Learning Portal",
        type: "website",
        images: [
            {
                url: "/og-image.png", // Recommended: 1200x630px image in your /public folder
                width: 1200,
                height: 630,
                alt: "TQP Portal Preview",
            },
        ],
    },
    twitter: {
        card: "summary_large_image",
        title: "Page Title | TQP Portal",
        description: "A clear, concise 1-2 sentence description of what this page does.",
        images: ["/og-image.png"],
    },
};

export default function Page() {
    return <div>...</div>;
}

```

#### 2. Dynamic Routes Template (`generateMetadata` in `page.tsx`)

For dynamic routes with params (e.g., `/enroll/[tutorId]`, `/admin/students/[id]`):

```tsx
import type { Metadata } from "next";

interface Props {
    params: Promise<{ id: string }>;
}

export async function generateMetadata({ params }: Props): Promise<Metadata> {
    const { id } = await params;
    
    // Fetch resource details dynamically (e.g., tutor or student name)
    // const item = await getItem(id);

    const title = `Details for Item #${id} | TQP Portal`;
    const description = `View attendance records, schedules, and profile updates for item #${id}.`;

    return {
        title,
        description,
        openGraph: {
            title,
            description,
            type: "website",
        },
        twitter: {
            card: "summary_large_image",
            title,
            description,
        },
    };
}

```
